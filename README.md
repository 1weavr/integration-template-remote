# Remote integration template

Tells your own server when a capture is made or fixed, and shows the facts it answers on each capture.

Press **Use this template** to make your own repository.

**Docs:** the calls it answers, their inputs and outputs, and the security rules: https://1weavr.com/docs/integration-templates#remote
